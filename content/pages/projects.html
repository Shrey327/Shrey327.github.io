Debugging practice · Free pilot

Bugger

Browser-based debugging practice for Python, Rust, JavaScript and TypeScript. The challenges use small programs adapted from documented open-source bugs: reproduce the failure, repair the cause and check the fix with regression tests.

Reports, hints and root-cause explanations keep the focus on understanding a failure rather than writing a solution from scratch.

macOS · Local utility

MacSweep

A local disk-cleanup utility for macOS with a browser interface. Cleanup actions are reviewed before they run, with Trash-first removal rather than immediate permanent deletion.

Packaged with its own Python runtime for Intel and Apple Silicon Macs. This is a local project, not a notarized public release.

Agent evaluation · ERP environment

miniRL

An inspectable accounts-payable environment for evaluating tool-using LLMs. It brings synthetic ERP data, a tool interface and task scenarios into an OpenEnv-based sandbox.

Independent graders inspect the final database state. A parallel evaluation harness runs the tasks. This is an evaluation environment, not a claim of a completed reinforcement learning training run.

AI engineering · Developer preview

Agentic IDE

A local-first Theia/Electron workspace that brings model connections, RAG, training, evaluation and run traces alongside the editor and terminal.

Agent edits are staged for review. Scoped MCP access lets coding agents work with the workspace. Version 0.2.1 is a developer preview, with implementation status and validation limits documented in the repository.

Inference and systems

Inference systems

InferenceX

A Qwen2.5-0.5B-Instruct inference server implemented in PyTorch. The public repository documents KV caching, continuous batching, paged memory, GQA head layout and experiments with CUDA graphs and a fused Triton attention kernel.

The README distinguishes experimental paths from the default serving path. CUDA graph decode is implemented separately. The fused kernel is behind a mode switch.
