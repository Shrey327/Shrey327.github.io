Inference systems

InferenceX

A Qwen2.5-0.5B-Instruct inference server implemented in PyTorch. The public repository documents KV caching, continuous batching, paged memory, GQA head layout and experiments with CUDA graphs and a fused Triton attention kernel.

The README distinguishes experimental paths from the default serving path. CUDA graph decode is implemented separately. The fused kernel is behind a mode switch.
